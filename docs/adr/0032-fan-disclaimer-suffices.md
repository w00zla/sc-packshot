# 0032. A fan-content disclaimer in the README is enough

- Status: accepted
- Date: 2026-11-06
- Scope: repository, documentation

## Context
[0004](0004-fan-content-and-no-game-data.md) left a formal check against Cloud Imperium's fan-content guidelines open
before wider distribution. packshot and its StarBreaker fork are about to be public.

## Decision
No separate legal review. The README carries an unofficial-fan-project disclaimer: not endorsed by or affiliated
with the Cloud Imperium group of companies, game content and everything packshot renders copyright Cloud Imperium
Rights LLC and Cloud Imperium Rights Ltd., Star Citizen® a registered trademark of Cloud Imperium Rights LLC. The
repository still holds no game data ([0004](0004-fan-content-and-no-game-data.md)). The StarBreaker fork's README
carries the same disclaimer.

## Consequences
- Users render from their own game copy; what they publish is their responsibility.
